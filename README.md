# CC-Data-Scraping

**Weight Loss & Metabolic Course Market Research Dataset (减重与代谢课程市场调研一手采集数据集)**

本仓库汇总了针对「减重与代谢营养课程」市场调研所采集的跨平台一手社媒、评论、电商、竞品定价及第三方榜单验证数据集。所有数据均已剔除账号 Cookie、密钥及运行缓存，仅保留清洗后的结构化数据表、原始样本快照、分析汇总说明及截图证据。

---

## 一、核心数据规模与锁定口径

| 维度 | 核心指标 | 口径说明 |
| :--- | :--- | :--- |
| **覆盖社媒平台** | **5 大平台** | 小红书、抖音、B站、知乎、微博（近半年真实抓取，已跨词去重） |
| **净有效内容** | **4,283 篇** | 内容主表共 4,314 行（含单列审计的无关噪音 31 篇） |
| **真实用户评论** | **93,410 条** | 净有效评论总表（已自动打标 5 类高价值意图） |
| **评论重标与人群分母** | **83,936 条** | 评论付费意图重标与上下文宽表（可判别四型人群的有效分母） |
| **人工精标样本** | **682 条** | 逐条人工编码标注样本，用于提取核心痛点、流失节点与用户原声 |
| **跨平台电商/社媒/供应链实证** | **500 条** | 跨平台电商、社媒与供应链一手样本实测 |

### 四大人群结构（分母 83,936 条）
- **A 指标型（39.7%）**：胰岛素抵抗（21.5%，含体检报告型与症状型）、脂肪肝（9.7%）、多囊 PCOS（8.5%）
- **C 场景型（32.0%）**：产后（8.3%）、中年（12.1%）、上班族、大小基数等
- **B 失败型（22.3%）**：反弹、卡秤（平台期中位 15 天）、情绪性进食
- **D 体量型（5.9%）**：大基数为主

## 三、合规与安全说明

1. **隐私与凭据脱敏**：本仓库已严格过滤所有 `.env`、`cookies.json`、登录态 Token、虚拟环境（`.venv`）、依赖包（`node_modules`）及 Python 序列化缓存（`.pkl` / `__pycache__`）。
2. **文件体积控制**：仓库内所有单文件均小于 95MB（最大单文件为 `评论上下文宽表.csv`，约 59.5MB），可直接通过标准 Git 克隆与拉取。
