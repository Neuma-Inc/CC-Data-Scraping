### 7.2 结构性风险（比单句更值得警惕）

1. **"不节食 + 不运动 + 不反弹"三者叠加，在能量代谢上难以同时成立。**
   若实际交付含食谱、热量限制、代餐或运动打卡，则"不节食不运动"构成引人误解；若真不含任何饮食/运动干预，则减重效果来源不明，可能指向未披露的药物/产品——两种情形都是监管重点。

2. **"随时退"与"3 个月服务"天然冲突。**
   3 个月服务一旦开始交付，"随时退"必然要设边界（已上课时、已发资料、已定制方案）。主页未披露边界，等于把一个必然有条件的条款说成无条件——这是退款纠纷最常见的起点。

3. **资质与话术错配。**
   主体经营范围明确排除"诊疗"和"需许可的培训"，但话术用的是"确保""体重管理""不反弹"这类接近医疗/疗效的表述。一旦私域里出现"肥胖症""胰岛素抵抗""多囊""逆转"等词，即触《广告法》第17条（非医疗广告不得涉及疾病治疗功能、不得使用医疗用语）。

4. **广告标识缺失风险。**
   若笔记属商业推广而未标"广告"，涉《互联网广告管理办法》第9条（以知识介绍、体验分享、消费测评等形式推销并附购买方式的，应显著标明"广告"）。因笔记未获取，**无法判断**。

5. **健康数据合规。**
   减脂陪跑必然收集身高、体重、体脂、月经史、病史等，属《个人信息保护法》第28条**敏感个人信息**，需单独同意、最小必要、告知处理目的。这是此类业务最常被忽略的合规盲区。

6. **预付式消费风险。**
   3 个月先付费 → 属预付式服务。若采用"概不退款""不得转让"等格式条款，按上述司法解释可能被认定无效。

### 7.3 不能说的话（给我们的红线清单）

- ✗ "不反弹""永久""根治""保证瘦 X 斤"
- ✗ "确保""100%""无效退款"（除非退款规则写死且真能执行）
- ✗ "不节食不运动"（除非交付里真的没有任何饮食/运动要求）
- ✗ "治疗肥胖/脂肪肝/多囊/胰岛素抵抗"
- ✗ "任何不满意随时退"（未写边界时）
- ✓ 可替代："3 个月掌握一套可长期执行的体重管理方法""按协议约定的退款规则执行"

## 9. 对我们课程的启示

### 值得抄的 3 点

1. **承诺结构极简：三个"不" + 一个时间锚 + 一个风险逆转。**
   "不节食 / 不运动 / 不反弹 / 3个月 / 随时退"——用户 3 秒能记住、能复述、能转介绍。
   我们的课程名和首屏，应该也能被用户在 3 秒内复述出来。**抄结构，不抄绝对化措辞。**

2. **把交付物定义成"能力"，而不是"斤数"。**
   "确保学会自我体重管理"比"3 个月瘦 20 斤"更耐打：既降低了效果举证压力，又天然支持高客单（卖的是能力，不是结果）。
   可改写为："3 个月，带走一套你自己能执行的体重管理方案。"

3. **用"最后一次"做身份定位。**
   "你的最后一次减脂"精准击中"减过很多次、每次都反弹"的人群——这是减重付费人群里付费意愿最强、也最容易被上一家伤过的一群。
   可改写为："最后一次学减脂"（把"减"换成"学"，规避效果承诺）。

### 最该避开的 3 点

1. **绝对化效果保证（"不反弹""确保"）。**
   这是广告法高风险区，也是退款纠纷里消费者最好用的抓手。省下的转化率，不够赔一次投诉。

2. **无边界退款承诺（"任何不满意随时退"）。**
   没有写清"已消耗课时/已交付资料/已定制方案如何计价"，等于给自己埋雷。要写就写成可执行的阶梯退款表。

3. **"不节食不运动"式的方法承诺。**
   只要交付里有食谱、热量控制或运动打卡，这句话就自相矛盾，用户截图对比就能举报。**要么改话术，要么改交付，不能两头占。**

### 额外一条战略提醒

这个账号的真正风险不在文案，而在**主体结构**：新公司（成立 6 个月）、100 万认缴、法人关联 8 家企业、注册地址两版不一致。
这种"轻主体 + 重承诺"的结构，起量快、跑路也快，但一旦规模化，投诉会直接打到主体和法人。
**我们不要学这个结构。** 我们要的是：主体清晰、合同清晰、退款规则清晰——这恰恰是可以拿来做差异化的信任资产。
