# 评论付费意图重标 · 规则词典

> 适用范围：`03_评论总表_原始_v4.csv` 全量评论（本版快照 103,968 行）。
> 目标：把“评论里有没有付费意图、是什么意图”拆成可复核的单标签；**宁可标 P9 不确定，不硬塞**。
> 配套：`重标汇总.md`（结果）、`评论上下文宽表.csv`（最终主表）、`rules.py` / `context_rules.py` / `strict.py`（实现）。

## 1. 标签体系

单选，优先级从高到低。一条评论只取一个主标签；同时出现多个意图时，取优先级最高的那个。

| 优先级 | 标签 | 名称 | 判定要点 | 典型正例 | 典型反例 |
|---:|---|---|---|---|---|
| 1 | P1 | 求购买链接/入口 | 显式问“怎么买/哪里买/求链接/怎么报名/怎么进群/求同款/求课程” | “肌醇在哪里买？”“怎么进群呢？”“求训练营链接” | “耳环哪里买的”（服饰）；“线上怎么买”（无对象） |
| 2 | P2 | 问价格/价格异议 | 问价、问收费、明确说贵/退费/不值，且有产品/课程对象 | “训练营多少钱？”“太贵了，能退吗？” | “牛肉多少钱一斤”（食物）；“不是很贵”（否定） |
| 3 | P3 | 求食谱/求带/求教程 | 求食谱、求教程、求跟练、求带、求更新，或短 how-to 问句 | “求一份食谱”“带带我”“怎么练臀？” | “还能怎么吃”（反问）；“怎么做不到”（质疑） |
| 4 | P4 | 已购竞品_正向 | **本人**买过/用过/打过，净正向 | “我买了，瘦了8斤，没副作用” | “刚下单，不知道有用不”（不确定） |
| 5 | P5 | 已购竞品_负向 | **本人**买过/用过/打过，净负向或明确副作用/反弹 | “我打了，恶心到住院” | “我妈打了恶心”（第三人称）；“我没副作用”（净正向） |
| 6 | P6 | 自报身体指标 | 自报体重/身高体重/BMI/体脂/腰围/血糖/尿酸/血压/诊断名 | “我160，125斤”“空腹血糖6.8” | “100斤用什么减肥药”（反问）；“我爸血糖高”（第三人称） |
| 7 | P7 | 核心痛点 | **第一人称、当前**的减重痛点/求助 | “平台期一个月不掉，咋办” | “我以前失眠，现在好了”（过去）；“大家都会反弹”（议论） |
| 8 | P8 | 经验/科普 | 课代表总结、多论据解释、第一人称经验分享 | “总结一下：胰岛素抵抗要……” | “感谢分享，太有用了”（纯称赞） |
| 9 | P9 | 无关/广告/情绪/证据不足 | 兜底：真无关、广告、纯情绪、过短、**有一点信号但证据不足** | “加油”“哈哈哈”“求地址”（无上下文） | — |

**P9 的双重含义**：P9 既是“真无关”，也是“证据不足、不敢硬判”的降级池。看 P9 占比时不要理解成“89% 的评论都无关”。

## 2. 判定总流程

```
原文清洗
  ├─ 去掉 @提及（防止回复者昵称“好贵啊”触发价格规则）
  ├─ URL/全角字符归一
  └─ 保留原始文本用于证据展示
        ↓
基础规则 rules.py
  ├─ 广告/引流（AD01/AD02）
  ├─ 领域词、竞品词、非竞品对象
  ├─ P1–P9 正则，按优先级取第一个命中
  └─ 输出：主标签、命中规则、规则证据、价格数字、具体指标、购买对象、竞品情感
        ↓
上下文补判 context_rules.py
  ├─ P5_CTX01：原帖药物语境 + 评论负向 → P5
  └─ P5_CTX02：初判 P7 + 原帖药物 + 自述副作用 → P5
        ↓
严格闸门 strict.gate
  ├─ 通过 → 保留标签
  └─ 不通过 → P9，命中规则=P9_GATE，保留“初判标签/初判规则”，置信度=低，备注“需人工复核”
        ↓
补判 strict.rescue
  └─ 仅对证据极明确的 P6/P3/P5/P7/P8，从 P9 捞回，规则名=Px_RESCUE
        ↓
反讽/玩梗/转述检测
        ↓
置信度降级
        ↓
子标签
```

## 4. 上下文规则（context_rules.py）

| 规则 | 触发 | 作用 |
|---|---|---|
| `P5_CTX01` | 原帖标题/正文含 `司美 / 替尔泊肽 / 玛仕度肽 / 二甲双胍 / 减肥药 / 处方 / 针剂 / 剂量`，评论含负向词，初判不是 P5 | 补判为 P5；用于“评论没写药名，但原帖是药物”的场景 |
| `P5_CTX02` | 初判 P7，原帖是药物语境，评论自述副作用（恶心/呕吐/失眠/脱发/月经紊乱/反弹等） | 从 P7 改判 P5；避免把“用药副作用”当纯痛点 |

**上下文充分性**：

| 状态 | 判定 | 对置信度的影响 |
|---|---|---|
| 是 | 标题 + 正文摘要都可读 | 不额外降级 |
| 部分 | 只有标题，或正文为空/过短 | P1/P2/P5 可能降为低 |
| 否 | 未关联到原帖，或原帖信息为空 | P1/P2/P5 置信度=低，备注“需人工复核” |

**硬约束**：P1/P2/P5 不得脱离原帖单独判定；原帖没有明确售卖/产品对象时，P1/P2 降级。

## 5. 严格闸门（strict.gate）

闸门的原则：**按“句子功能 + 对象 + 局部证据”判定，而不是关键词出现即算**。每一类都要求局部窗口（通常是包含购买/痛点动词的那一句及其后两句）里有显式证据；否则降为 P9。

| 标签 | 必须具备（局部证据） | 直接排除 / 降为 P9 |
|---|---|---|
| P1 | 显式求购/求入口/报名/入群/求同款课程；或“怎么买/哪里买”且有 `P1_OBJECT`（课程/训练营/代餐/补剂/药/血糖仪/食谱/产品…）或原帖有售卖/产品信号 | 广告/自我引流；>120 字且无问句；营养师考证帖；已购陈述；食物/服饰/日用品（`NON_COMP_OBJECT` 且无竞品）；“怎么买”无对象；“等…再/如果”假设意愿 |
| P2 | 问价（多少钱/怎么收费/价格/学费/报价）或明确价格异议（太贵/好贵/退费/退款/不值），且有 `P2_OBJECT` 或原帖售卖/产品信号 | 医疗费用（医院/挂号/检查/糖耐/OGTT/体检/手术）；考证；价格建议（“不用/没必要…贵”）；否定式（“不贵/不算贵/不是智商税”）；泛化“都是智商税”无具体对象；食物/日用品价格；>150 字长文顺带 |
| P3 | `P3_REQ`（求食谱/教程/带/跟练/出一期/食谱有吗…）或短 how-to 问句（≤25 字；或 ≤90 字且带问号/吗/呢/请问/求） | 非减重语境；广告；反问/陈述（“怎么吃怎么…/不然你以为/没教我怎么/咋吃都不行/还能怎么吃/怎么做不到/怎么减都…”）；>120 字且无 `P3_REQ`；建议/科普（你/大家应该/可以/不要…）；无请求的陈述 |
| P4 | **本人**购买/使用（`_purchase`）+ 竞品/产品对象（或原帖是产品且本人购买）；净正向（pos>0 且 neg=0） | 广告；“同事/朋友/我姐/我哥/我爸/我妈/老公/老婆/闺蜜/她/他”等第三人称（除非“我也打/吃/用/买”）；食物/日用品；软件/工具；副作用被否定（“没有便秘/没副作用”） |
| P5 | **本人**购买/使用 + 竞品/产品对象；净负向（neg>0 且 neg>pos）或出现严重副作用（`SERIOUS_NEG`：副作用/反弹/心悸/失眠/恶心/呕吐/伤肾/月经/住院…） | 同上；净正向；第三人称；无本人购买；劝阻/建议他人；副作用被否定 |
| P6 | 具体指标（斤/kg/体脂/BMI/血糖/尿酸/血压/腰围/多囊/脂肪肝/甲减/胰岛素抵抗）+ 自述（“我/本人/自己”在同一句） | 广告；无数字；反问“用什么减肥药”；“我感觉/我觉得”无数字；只有诊断名没有“我有/查出/确诊”；父母/家族/第三人称；仅议论 |
| P7 | 第一人称当前痛点：`P7_PAIN` + （我/自己/咋办/怎么办/救命/哭/求助）在同一句；过去叙述必须同时有“现在/目前/最近” | 广告；询问反弹风险；仅“馋”且无失控；泛化“很多人/大家”无我；“制造焦虑”态度；解释性“查了一下/看来/说明/原来”无求助；科普/否定式（“有平台期/都会反弹/没反弹/没有便秘”）；建议类；成功经验；过去已愈；只有“后来/后面”无现在 |
| P8 | 减重语境 + （总结词且 ≥20 字；或 ≥40 字且 ≥2 个解释论据；或 ≥40 字第一人称经验） | 非减重；AI 总结指令（`@xx 总结/归纳`）；广告；纯称赞/互动（<80 字且无总结词） |
| P9 | 兜底 | 不适用 |

**闸门失败时的字段**：

- `主标签 = P9`
- `命中规则 = P9_GATE`
- `初判标签` / `初判规则` 保留原判，便于复查
- `置信度 = 低`
- `备注` 含“需人工复核”及具体原因（如“原帖无明确售卖/产品对象”）

## 6. 补判规则（strict.rescue）

补判只从 P9 里捞“证据极明确”的少量类型，规则名统一为 `Px_RESCUE`，避免闸门过严导致高价值评论全部丢失。

| 补判 | 触发 | 置信度 |
|---|---|---|
| P6_RESCUE | ≤40 字自报体重/体脂/BMI，且非第三人称、非已购/下单、非“用什么减肥药” | 中 |
| P6_RESCUE | “数字-数字” + 瘦/减/掉 + 我/自己，且无用药词、非第三人称 | 中 |
| P3_RESCUE | how-to 问句（怎么吃/练/减/计算/安排/搭配/做到）+ 问号/吗/呢/请问/想问，≤60 字 | 中 |
| P3_RESCUE | “怎么计算” ≤30 字 | 中 |
| P5_RESCUE | 本人用药 + 负向且无正向、副作用未被否定；或原帖是药物 + 本人 + 副作用（评论没写购买动词） | 中/低 |
| P7_RESCUE | 第一人称痛点 + 求助词（咋办/怎么办/救命/哭/求助/难受/痛苦） | 中 |
| P7_RESCUE | 第一人称失眠/焦虑/抑郁/关节痛/暴食/闭经，无求助词也补 | 中 |
| P8_RESCUE | ≥100 字 + 总结/笔记/核心观点/要点/梳理 + 减重语境 | 中 |

## 7. 反讽 / 玩梗 / 转述

| 标记 | 触发示例 | 处理 |
|---|---|---|
| 反讽 | 呵呵、典中典、阴阳、说反话、你猜、太好笑了、可真、狗头/doge/🐶 | 单独标记；不计入正负面；P4/P5 的“竞品情感”改为“不确定” |
| 玩梗 | 玩梗、整活、bushi、开个玩笑、绷不住、乐死、笑死、梗 | 同上 |
| 反讽+玩梗 | 两类同时命中 | 同上 |
| 转述 | 有人说、据说、听说、别人说、评论区说、up主说、博主说、医生说、我妈说、朋友说、转述、原话、引用、搬运、看到有人说 | 单独标记；P4/P5 情感记为“不确定”；P9 的转述保留（因为转述本身可能是信息） |

**只对已有意图标签的评论标记**（P9 除转述外不标），避免把日常玩梗刷满。

## 8. 置信度

| 置信度 | 含义 | 典型情形 |
|---|---|---|
| 高 | 显式规则 + 对象明确 + 上下文完整 | “训练营怎么报名，多少钱？” |
| 中 | 规则命中但文本短、对象靠上下文、或原帖只部分可读 | “求链接”（原帖是课程） |
| 低 | 闸门降级、上下文缺失、反讽/玩梗/转述、对象不确定 | “线上怎么买”无对象；“我打了，恶心”（原帖未关联） |

**降级规则**：

- P1/P2/P5 上下文“否” → 低 + “需人工复核”。
- 反讽/玩梗/转述 → 低 + “需人工复核：xx，情感不计入正负”。
- 闸门不通过 → P9 + 低 + “需人工复核”。

## 9. 特殊处理与已知坑

### 9.1 @提及剥离

回复型评论常以“@某某 好贵啊”开头，昵称本身可能含“好贵/求链接”等词。分类前先执行：

```python
text = re.sub(r"@[^\s:：]+", "", text)
```

只影响分类，不改原始评论文本。

### 9.2 非竞品对象

以下词出现在评论里，默认是食物/日用品/身体部位，不是减重竞品；除非同时有 `COMPETITOR` 或原帖产品信号，否则不判 P1/P2/P4/P5：

`韭菜、肌肉、菜、酸奶、蓝莓、麦片、短袖、T恤、卫衣、外套、腰垫、盒子、收纳、衣服、裤子、鞋、上衣、背心、裙子、帽子、首饰、口红、化妆品、手机、电脑、电瓶车、家具、玩具、猫、狗` 等。

> 注：`耳环/耳钉/项链/手链` 目前只被“首饰”部分覆盖，第四轮样本里的“马马老师的耳环哪里买的”仍被误判为 P1。这是下一版应补的 `NON_COMP_OBJECT` 缺口；补上后需重跑全量，本版输出尚未包含该修正。

### 9.3 广告/引流

`AD01`：加微/加V/扫码/二维码/免费领取/小黄车/橱窗/优惠券/包瘦/不瘦包退/机构招生话术。
`AD02`：URL + 优惠/领/购/下单/折/链接 等交易词。
`AD_PROMO`：我的咨询/课程/训练营、私信/主页/置顶/加V、合集/清单+站外链接、套餐定制、90%效果等。

广告优先判 P9，不进入 P1/P2。

### 9.4 价格数字与具体指标

- `是否含价格数字` / `价格数值` / `价格原文`：从评论文本抽取金额（元/块/万），用于价格异议分析；不代表一定是产品价格。
- `是否含具体指标` / `指标明细`：抽取体重、BMI、体脂、血糖、尿酸、血压、腰围等，供 P6 复核。
- `购买对象`：从评论中识别“课程/训练营/代餐/司美/血糖仪…”等对象，供 P1/P2/P4/P5 复核。
- `竞品情感`：正向/负向/混合/不确定；反讽/玩梗/转述时强制“不确定”。

### 9.5 旧标签列

`旧标签` 来自旧表“评论价值分类”，同样是关键词产物，抽样发现类①含蔬菜价格、糖耐量费用等误判。**仅作对照，不参与本次判定。**
