## 四、跨平台共性 / 差异

### 共性

1. **胰岛素抵抗/血糖/控糖是唯一五个平台都进 Top5 的话题**（4.3%–6.0%）。这是全平台的“最大公约数”。
2. **价格/购买在五个平台都最低**（0.5%–1.2%）。P9 不是交易层，不能拿它估付费率。
3. **情绪/暴食在五个平台都不低**（3.1%–4.5%），说明“坚持/情绪”是跨平台的课程需求。

### 差异

1. **运动**：B站 8.5%、知乎 6.7%、抖音 5.3%，小红书只有 4.6%。B站/知乎更“训练原理”，抖音更“跟练”，小红书更“吃”。
2. **药物/补剂/手术**：B站 5.8%、知乎 5.4%、微博 5.9%，小红书 3.3%、抖音 2.8%。B站/知乎/微博更“成分党/药物讨论”，小红书/抖音更“吃和练”。
3. **怎么吃/食谱**：小红书 4.4%、微博 4.8%，B站 2.8%、知乎 2.7%。小红书是“食谱场”，B站/知乎是“原理场”。
4. **监督/训练营/营养师**：知乎 4.4% 最高，但知乎的关键词里含“训练营/营养师/避坑”，更像“选择/避坑”，不是“求陪跑”；小红书 2.7% 更像“找搭子/打卡”。
5. **睡眠/熬夜**：B站 3.1% 最高，知乎 2.0%，其他 0.9%–1.4%。B站用户更关注“熬夜/睡眠/代谢”。
6. **产后/多囊**：知乎 2.5%、抖音 2.4%、微博 2.0%，小红书 1.6%、B站 1.4%。

## 五、对课程方向的含义

### 1. 课程核心：代谢机制 + 怎么吃 + 怎么动 + 怎么坚持

- **代谢机制**：胰岛素抵抗/血糖/控糖是五平台最大公约数，必须放在第一模块。
- **怎么吃**：碳水/蛋白/食谱/分量，小红书和抖音最强，是“拉新内容”的主力。
- **怎么动**：B站/知乎/抖音更强，课程里要有“居家跟练/力量入门”，但不能做成健身房私教。
- **怎么坚持**：情绪/暴食/监督/打卡，五平台都有人提，是“交付”的核心。

### 2. 平台内容分工

| 平台 | 内容重点 | 课程角色 |
|---|---|---|
| 小红书 | 食谱/吃法 + 胰岛素科普 | 种草 + 私域承接 |
| 抖音 | 跟练/运动 + 大基数 + 情绪 | 放量 + 成交测试 |
| B站 | 运动原理 + 药物/CGM/成分党 | 信任背书 + 深度测评 |
| 知乎 | 运动 + 药物 + 训练营/营养师避坑 | 决策辅助 + 专业背书 |
| 微博 | 药物 + 胰岛素 + 明星/医生 | 声量，不进主结论 |

### 3. 课程模块建议

1. **代谢模块**：胰岛素抵抗、血糖、平台期、产后/多囊。
2. **吃法模块**：碳水替换、蛋白质够不够、外卖/食堂、分量/拳头。
3. **运动模块**：居家跟练、走路、深蹲/平板，按大基数/小基数分。
4. **坚持模块**：情绪性进食、暴食、打卡、监督、复盘。
5. **避坑模块**：GLP-1/代餐/补剂/手术的边界，只做科普，不卖药。

### 4. 不要做的事

- 不要用 P9 的“价格/购买”比例估付费率；它只有 0.5%–1.2%。
- 不要把“运动”当成所有平台的第一需求；小红书的第一需求是“怎么吃 + 胰岛素”。
- 不要把“训练营/营养师”在知乎的高提及，当成“知乎用户想买陪跑”；那更多是“避坑/选择”。

## 六、限制

1. **关键词子串匹配**：会漏同义表达，也会误伤（“药”匹配“药店”）。
2. **多命中**：一条评论可命中多个话题，各列相加 > 100%。
3. **平台分母不同**：微博只有 1,730 条 P9，比例波动大；B站/抖音样本大，更稳。
4. **平台特有词会抬高某话题**：知乎的“训练营/营养师”、B站的“GLP-1/CGM”都加了词，解读时要看原始关键词。
5. **100 条人工细分只在小米书完成**；其余四平台的 A–F 细分待补，本文件只做话题矩阵。
6. **P9 是混合类**：包含“真无关”和“证据不足”，不是“全量用户”。
