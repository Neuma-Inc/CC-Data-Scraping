# v3 抓取词表说明

## 一、这份表怎么来的

1. **母词 8 个**（定稿）：减肥、减脂、瘦不下来、控糖、血糖高、复胖、减肥反弹了怎么办、营养师
2. **词干 43 个**：8 个母词 + 35 个补盲区词干（男性/应酬/夜班/维持期/价格/手术/中医/年龄/多囊/脂肪肝/药物/素食/家庭/便秘/打鼾）
3. **五个平台**各跑下拉联想，把平台的联想词全部收下来
4. 排雷：财经、游戏、考证、琵琶类全删；不沾减重话题的词根也删
5. 打分：跨平台数 ×3 + 能被多少个词干带出来（说明是枢纽词）
6. 归到 C01~C08，按分类分平台

## 二、这轮的规模

- 五平台联想词 + 关联热搜（去重后）：**1329** 条
- 排雷删掉：6 条；不沾减重删掉：85 条；疾病科普删掉：12 条；长度不合：1 条
- 过滤后合格候选：**1225** 条
- 再按分类保底 + 优先级，选进最终抓取词表：**173** 个
- 名义抓取量：约 **10,720** 篇（实际以平台返回为准，多数词拿不满目标篇数）

## 七、必须承认的四个缺口

1. **微博是空白**。访客态校验过不去，只能改用热搜话题入口单独抓，抓回来的东西不能和另外四个平台横比。
2. **小红书这轮只拿到 1 个母词的标签**（中途弹滑块验证码）。所以这版的 8×8 重合度矩阵实际是「B站 8 个母词 + 小红书 1 个」算出来的，B站占绝对主导。
3. **抖音拿不到内容标签**，只能拿联想词，所以抖音的分类占比算不出来，也没法和 B站/知乎做标签层重合度。
4. **目标篇数是预算不是预测**。平台实际能返回多少要跑起来才知道；微博尤其薄（v1 时每词只有 5.4 篇）。

## 八、怎么用

1. 先跑 P1（68 个词），确认每个词真能抓到 30 篇以上
2. P1 跑通再放 P2/P3，避免一上来就把平台风控打满
3. 小红书频控敏感，单账号每天控制在 300 篇以内，词表里小红书相关的最多分 3 批跑
4. 抓回来的数据按词表里的「业务分类」直接落 C01~C08，不用二次人工归类
5. 表里「来源」列标了 `强制补盲` 的词，是探针没吐出来但业务上必须覆盖的（男性、价格、维持期、手术、中医等），优先级一律按 P1

## 九、词表里三个需要解释的坑

1. **「全家减脂餐」不是全家一起吃饭**。平台联想出来的「全家减脂餐价格」「全家便利店减脂餐」指的是全家便利店（FamilyMart）的减脂餐，不是家庭餐。这个词留着有用（便利店是真实购买场景），但不要当成家庭餐人群的证据。家庭餐方向要另外用「一家人怎么吃」「给家人做饭」这类词补。
2. **C06 里「复胖」近义词很多**（复胖了怎么办 / 复胖怎么办 / 复胖怎么减肥 / 复胖后怎么减肥 / 减肥后复胖怎么办）。这说明这个说法在平台上确实高频，但抓回来高度重复。实际抓的时候这 5 个词只跑前 3 个就够，重复的靠笔记 id 去重即可。
3. **表里有 4 个「大盘基线」词**（减肥、减脂、控糖、复胖）。它们只有 2 个字，搜出来最泛，混着大量百万粉大号和无信息量的内容。留着不是为了抓细分人群，是为了做**对照组**：拿它们的数据当分母，才能说清「细分人群的痛点和大盘有什么区别」。抓的时候建议单独存一张表，不要和细分词混在一起算占比。
