# XHS「减重服务商家 TOP20」可行性结论

- 日期：2026-11-04
- 范围：小红书网页端（已登录 profile，headless）
- 目标：按「已售」排序取 20 家减重服务商家，记录价格与销量
- 状态：**已停抓，未写 CSV；用户决定先用灰豚试，不再抓 XHS 商家销量**

## 结论先行

1. **按「已售」排名的服务商家 TOP20：不可行。** 网页端店铺页只给商品与价格，不给已售；搜索页没有商品/店铺入口；服务类成交走专栏/私域，平台不公开销量。
2. **「GMV 代理 = 价格 × 已售」同样不可行**（服务类没有已售）。
3. 若灰豚口径不足，备选替代口径是 **内容 + 价格 + 影响力**：商家池从笔记里取，价格从笔记/封面/置顶评论取（标"笔记自述"），影响力用粉丝与笔记互动，不再声称销量。

## 三、为什么拿不到

1. **网页端店铺页不渲染已售。** 页面只有「商品 / 价格 / 卖家口碑」，点「销量」排序也只是换顺序，不显示数字。
2. **搜索页没有商品或店铺入口。** 搜索页只有「全部 / 图文 / 视频 / 用户」四个标签，服务商以笔记形式出现，卡片上没有已售。
3. **平台电商以实物为主。** 既有报告《平台付费产品_价格带》已核对：小红书电商技术服务费条目只覆盖实物；服务/课程走专栏，专栏销量与抽成均未公开。服务类成交多在私域，平台不记录。
4. **网页端有 App 引导。** 店铺页顶部固定「立即下载小红书App」；商品详情、下单等能力在 App 内，网页端未开放。
5. **接口层没有销量字段。** 页面加载期间拦截的 `/api/` JSON 没有任何 sale/sold 字段；SKU 接口响应未再解析（按要求停）。

## 五、可行性与替代口径

### 判定

| 目标 | 可行性 | 说明 |
|---|---|---|
| 已售排序 TOP20 | ❌ 不可行 | 无已售字段 |
| 价格带（引流价/主价） | ✅ 部分可行 | 笔记自述价、封面价、置顶评论价，需标"未验证" |
| GMV 代理（价格×已售） | ❌ 不可行 | 无已售 |
| 商家影响力排名 | ✅ 可行 | 粉丝、笔记赞/评/藏、更新频率 |

### 建议替代口径（待确认）

**「内容 + 价格 + 影响力」商家榜**

- **商家池**：8 个词各取首屏/前 2 页笔记（减脂营、减脂陪跑、1v1营养师、体重管理、减重训练营、减肥私教、线上减脂、控糖减脂），抽出笔记中明确提供服务的账号，去重。
- **价格**：抓标题、封面文字、正文、置顶评论中的报价；分别记「引流价/体验价」与「主推套餐价」，多档全记，不平均。
- **影响力**：粉丝数、笔记数、近 30 天笔记互动（赞+评+藏）、是否挂店铺/专栏入口。
- **排名依据**：影响力（互动或粉丝），字段写明"非销量"。
- **成交**：只有店铺/专栏公开数字才写；其余一律"需登录/未验证"。
- **产出**：`小红书_减重服务商家_内容价格影响力.csv` + 分析（价格带分布、影响力分层、内容卖点）。
- **预期**：20–30 家账号；每家 3–6 档价格（视披露）；**可验证已售预计为 0**（除非发现例外店铺页）。
